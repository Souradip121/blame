Private repo, or hit GitHub’s limit? Add a token

Without a token GitHub allows 60 lookups an hour from your network; one repo takes about 5 to 15. A token raises that to 5,000 and lets this page read private repos you can see.

  1. Make a fine-grained token on GitHub with read-only access (Contents and Metadata are enough).
  2. Paste it here.

It stays in this tab only (sessionStorage) and is sent to api.github.com and nowhere else.
